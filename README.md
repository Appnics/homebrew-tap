# Appnics Homebrew tap

```sh
brew install --cask appnics/tap/liquidwave
```

| Cask | App |
|---|---|
| `liquidwave` | [LIQUIDWAVE](https://liquidwave.app) — a music visualizer for Mac that draws whatever you play. Free to download; a one-time purchase inside the app unlocks every scene. Requires macOS 14.2 or later. |

The app updates itself (Sparkle), so `brew upgrade` leaves it alone unless you pass `--greedy`.
